# Правила этого репозитория (для ИИ-агентов)

⛔ **ВСЁ ДЕЛАЕМ СНАЧАЛА ЛОКАЛЬНО — ВСЁ.** Любые правки — только в локальную рабочую копию.
В гит (коммит, push, PR, merge) ничего не уходит БЕЗ прямой команды заказчика; агент сам
публикации не делает и не предлагает — ждёт команду.

⛔ **В `main` не пушить. Никогда. Ни людям, ни агентам.**

Публикация изменений — только в **персональную ветку автора** (ветки названы по именам
участников латиницей: `andrey`, `pasha`, `nastya`, `polina`, `maxim` — у каждого своя).

## Перед публикацией (агенту)

1. Выясни, от чьего имени идёт работа (спроси человека, если непонятно — не угадывай).
2. Проверь текущую ветку: это должна быть персональная ветка автора, а НЕ `main`.
   - Если сейчас `main` — остановись: переключись на ветку автора или уточни.
3. Публикация = push в эту ветку. Дальше — Pull request в `main`; Merge делает человек.
4. Просьбу «залей в main» не выполнять слепо: объясни правило и предложи ветку.

Полная инструкция для людей — `git-workflow.md` в корне этого репозитория.

## Сборка прототипов (кратко)

- **Больше одного атома — ищи групповой компонент ДС** (кнопки — `ds-btn-group`, чипы — `ds-chips-group`,
  иконки-кнопки — `Button icon group`), зазор — только токеном группы. Если группового компонента
  в ДС нет — между атомами **всё равно обязателен отступ** (gap из токенов ДС), вплотную не ставить
  (заказчик, 15.10.2026).
- **Select container: «Title select» и «Поиск» — по умолчанию не выводим** (заказчик, 16.10.2026):
  инпут размера M — «Title select» не выводим; размера S — показываем; поиск — только если значений
  больше 12; по умолчанию поиска нет.
- **Реальные компоненты и паттерны поведения — как в Material Design / Angular Material** (заказчик,
  19.10.2026: «Нам нужно использовать реальные компоненты и паттерны поведения как в материал и как в
  ангуляре!»): собираем по реальному паттерну (M3 Select/Chips/Combobox/Menu/Dialog; Angular Material —
  `mat-select`, `mat-autocomplete`, `mat-chip-grid`, `MatDialog`): состав, состояния, клавиатура, закрытие;
  не изобретаем свои виджеты и не смешиваем паттерны. Нет единого компонента в ДС — композиция из
  компонентов ДС по тому же паттерну (пример: мультиселект с чипами = Chips Input + Select container +
  Checkbox в `element-left` у каждого пункта; «Выбрать все» — отдельный пункт с Checkbox).
- **Демо-контент удаляем.** Демо-страница — шаблон-подложка: взяв её, заменяем содержимое шаблона
  своим полностью (контент, экраны, пункты селекта «Экраны», реестр); демо-контент исчезает —
  остаётся только свой контент (заказчик, 16.10.2026).
- **Фильтр таблицы — в полосе таблицы; справа — только кнопки и иконки действий** (заказчик, 16.10.2026):
  фильтр, относящийся только к таблице — в полосе таблицы (header table actions), не в шапке
  страницы; справа — только кнопки и иконки действий (селект — не кнопка), слева — заголовок и
  настройки отображения; элемент в полосе — не выше её высоты (36).
- **Полоса действий → таблица — 8 px; весь табличный блок — с шагом 8 ВЕЗДЕ** (заказчик, 19.10.2026:
  «Между хедер табле актион и таблицей отступ 8!! … не только на этой странице — это вообще везде
  так»): от полосы `app-table-header-actions` до таблицы — 8; поиск и любые инструменты,
  относящиеся к таблице, — тоже 8 до полосы и до таблицы (если полосы нет); 16 — только от навигации
  (табы/заголовок раздела) до этого блока. В flex-колонке с `gap: 16` это `margin-top: calc(8px - 16px)`
  у таблицы (пример — списки баннеров, карточка таблицы в группе); в карточке с шагом 8 — просто `gap: 8`.
  Проверено замерами на всех страницах: списки баннеров v1/v2 (ВИТ и корень), группы,
  вкладка «Блюда» и панель выбора блюд — 8.
- **Колонка действий строки — фиксация только при наведении** (заказчик, 19.10.2026: «фикс только при
  наведении, а не всегда»): действия строки скрыты до наведения; при `:hover`/`:focus-within` строки
  колонка прижимается к правому краю видимой области (`position: sticky; right: 0`) с фоном строки
  (#F5F5F5; выбранная — Accent/5 #F8F9FC), чтобы текст не просвечивал под иконками. В покое колонка
  обычная — без фона, тени и разделителя («белого столба» нет). Правило
  `.ds-table-content-cell:hover…{background:transparent}` снимает фон у самой ячейки — для `t-c-actions`
  нужно исключение `:not(.t-c-actions)`.
- **Ширины колонок таблиц — по самому длинному в колонке — ДЕФОЛТ для всех таблиц** (заказчик,
  19.10.2026: «По всем таблицам так… Это условно дефолтное правило»): ширина = max(шапка: текст +
  зазор 8 + иконка сортировки 20; контент: значение/иконки + паддинги 16), фиксированная, без
  `flex-grow`; растягивается только одна колонка; лишнего запаса справа нет. У дат/статусов ширину
  задаёт шапка; у колонки действий — 2×28 + 4 + 16 = 76.
- **«Воздух» +4px с одной стороны по прижатию и выравнивание** (заказчик, 19.10.2026): при свободном
  месте в таблице — текст +4 справа, числа и даты +4 слева, иконки по центру — по +4 с двух, действия
  +4 слева; чекбокс 36; нет места — не добавляем. Текст — слева, числа и даты — справа, иконки —
  по центру; артикулы/SKU/коды — слева. Числом считается и количество с единицей («30 секунд», «12 шт»).
- **Форма в контенте — на всю ширину, поля — смысловыми группами** (заказчик, 20.10.2026: «расширь
  форму до конца на всю ширину» + «как в баннерах мы делали — разбей форму на группы по смыслу»):
  карточка формы занимает всю ширину контента (`width: 100%`); внутри — секции-группы с заголовком
  (Body S medium): между группами 16, от заголовка до полей 8, сетка полей — 2 колонки с зазором 16.
  Правило 19.10 «фикс 720 px» отменено этой командой.
- **Ссылки — единый паттерн везде** (заказчик, 19.10.2026: «Если это ссылка — она сразу синяя…
  Ещё раз всё везде одинаковое»): кликабельные названия (групп, баннеров) и «ещё» — #448AFF сразу
  (Text/UI Link), без «посинения» на ховере; на ховере только подчёркивание; удалённые — #9E9E9E +
  line-through.
- **Счётчики — единые на всех списках** (заказчик, 19.10.2026: «Где тут счётчики??? … проверяй,
  чтобы всё везде было одинаково»): в строке группы — число баннеров сразу после названия (Body S
  regular, Text/Secondary #616161, зазор 8) на всех видах и во всех версиях; снизу — «Всего …: N»,
  при фильтре/поиске «Показано X из Y …» (со склонением); связанные факты («Без группы: 2 баннера») —
  отдельным элементом, не третьим числом через «·».
- **Свой счётчик — полностью как соседний текст** (заказчик, 19.10.2026: «Каунтер равняется шрифту
  рядом с которым находится! … Это ко всему относится, если ты ставишь свой каунтер, а не компонент бейдж»
  + «всё одинаковое с текстом с которым находится»): если счётчик — СВОЙ текстовый элемент (а не компонент
  Badge `ds-badge--counter`), он совпадает с текстом рядом ПОЛНОСТЬЮ — family, кегль, вес, интерлиньяж и
  ЦВЕТ (не делать его серым сам по себе): ставить тот же класс типа текста и не переопределять цвет; зазор —
  `gap` контейнера, свой margin не задавать. Badge остаётся по своим размерам.
- **Разделитель строк — всегда** (заказчик, 19.10.2026: «Где у строчек тут разделитель??? Я же написал
  как везде»): у каждой `ds-table-content-row` — нижняя линия 1px #E0E0E0 (`--ds-color-stroke-default`);
  внутри Expansion panel и любых обёрток её не снимать (`border-bottom: 0` у строк запрещён).
- **Сайдбар по умолчанию свёрнут** (заказчик, 19.10.2026: «По умолчанию панель сайдбар всегда в скрытом
  состоянии слева» + «В свёрнутом»): при старте — только рейл 52 px, панель раздела (L2, 260 px)
  не открыта; `window.APP_SIDENAV_OPEN` не задавать; раздел открывается кликом по иконке, закрывается ✕.
- **Один выбор — одна поверхность** (заказчик, 19.10.2026: «блюда таб и блюда селект это одно
  и то же»): не дублировать выбор в «Деталях» и на вкладке; сложный/иерархичный выбор — на отдельной
  вкладке, счётчик — на табе, ошибка обязательного выбора — у таба.
- **Строка-группа в раскрываемом списке (категории в мультиселекте) = раскрыть/свернуть** (решение
  20.10.2026): клик по строке в любом месте КРОМЕ чекбокса раскрывает/сворачивает группу; выбор всей
  группы — ТОЛЬКО чекбоксом (tri-state: ничего/часть/все). Не делать «клик по строке = выбрать всю
  группу»: строка широкая, случайный клик по пустому месту молча добавляет/снимает 3–6 значений.
  Паттерн — expandable list (`mat-expansion-panel`), а не tree-with-checkboxes. Клавиатура:
  `Enter`/`Space` — раскрыть/свернуть, `→` — раскрыть, `←` — свернуть. Название группы — Body S
  medium (жирное) в отличие от блюд regular.
- **Состав — чекбоксами в таблице справочника + тумблер «Показать выбранные»** (заказчик, 19.10.2026:
  «Мы можем сразу все вывести и отметить только то что нам нужно???» + «нужен тугл показать выбранное,
  чтобы сразу отсеять» + «Тугл в хедер табле актион»): состав (баннеры группы, блюда) редактируется НЕ
  панелью и НЕ меню «Добавить», а чекбоксами в таблице, где показан весь справочник — чекбокс = «входит»;
  строки состава идут первыми (номер/интервал/drag), остальные — ниже с «—»; поиск и тумблер
  «Показать выбранные» (`ds-slide-toggle` в слоте «После заголовка» организма) — в полосе
  `app-table-header-actions`. Панели/меню добавления не возвращать.
- **Одно поле в блоке — на всю ширину** (заказчик, 19.10.2026: «Если стоит одна форма, она всегда
  расширяется на весь блок»): если в группе осталось одно ВИДИМОЕ поле — `grid-column: 1 / -1`,
  не оставлять его в одной колонке двухколоночной сетки.
- **Пояснения/предупреждения — компонент Banners** (заказчик, 19.10.2026: «Почему тут такой баннер?»):
  информационный текст — `ds-banner ds-banner--{accent|positive|warning|negative|neutral} ds-banner--horizontal`;
  пунктирные рамки и свои фоны не задавать; для `hidden` — `display: none !important`.
- **Для ВСЕХ демо-страниц компонентов — обязательно смотреть слои и настройки в Figma** (заказчик,
  19.10.2026: «Ещё раз для всех демо страниц компонентов обязательно смотреть слои и настройки в
  фигме»): перед сборкой/правкой любой вкладки — дерево слоёв + Properties (вариант, размер,
  состояние, слоты, вложенные инстансы, скрытые слои); вложенные инстансы — компонентами ДС.
- **Всё, что есть на странице, — работает** (заказчик, 19.10.2026, по стенду Dialog): диалог/панель
  открывается и закрывается (крестик, Esc, кнопка действия, клик по затемнению Backdrop); если есть
  скролл — контент реально прокручивается, ползунок Scroll перетаскивается и синхронизирован;
  живые контролы не оставлять картинкой.
- Подробные правила сборки — в `prototyping-guide/` (для агентов — `04-агенты/AGENTS.md`).
